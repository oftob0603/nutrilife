The single surface primitive — every panel, list row and result block in NutriLife is a Card.

```jsx
<Card>
  <div style={{ font: 'var(--type-card-title)' }}>Bugungi ovqatlar</div>
</Card>
```

Depth comes from the background/card colour difference plus the hairline — never add a shadow. Nested elements drop 8px of radius (card 20 → image 12).
