Renders one Lucide glyph at the brand's stroke weight (1.75) in `currentColor`.

```jsx
<Icon name="camera" size={24} />
```

Load `https://unpkg.com/lucide@0.454.0/dist/umd/lucide.js` on the page first. Icons are monochrome and inherit text colour; never tint them lime. A 20px icon still needs a 44px tap target around it.
